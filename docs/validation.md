# 表示と動作の確認

## 実行記録

2026-10-24、Windows 上で実施。

| 確認 | 結果 |
| --- | --- |
| SDK 9.3.0 + Java 17 によるデバイス指定なしの strict 型チェックビルド | 通常・テスト用ともに BUILD SUCCESSFUL |
| Edge 530 を指定した strict ビルド | 通常・テスト用ともに BUILD SUCCESSFUL、警告なし |
| Monkey C テストの実行 | Edge 530 / API 3.3.1 で3件 PASS（failed=0, errors=0） |
| 画面分割 | 7 Fields A の横長・半幅の枠で表示と長い曲名の省略を確認 |
| 背景色 | 白背景の黒文字、黒背景の白文字を確認 |
| 日本語 | Japanese (jpn) 設定で曲名・アーティスト名と、半幅枠での末尾省略を確認 |
| サンプル固定用の設定 | 固定表示のロジックはテスト済み。SDK の設定エディターでは JSON 読み込みエラーのため UI 操作は未確認 |
| 実機 | 未確認 |
| iPhone からの Spotify 情報取得・送信 | 未実装 |

デバイス指定なしのビルドには `Invalid device id ... edge530` の警告が出る。
これは構文・型の確認に限られ、Edge 530 向けの互換性・メモリ・フォント・実行を検証した結果ではない。
`bin/generic*.prg` は端末へ配布しない。

## 確認できた枠の寸法

公式の Edge 530 デバイス定義（SDK Manager で2026-10-24に取得）に記載された描画領域。
画面全体の寸法と区別する。枠間の境界線は含まない。

| レイアウト | 横幅246pxの枠の高さ |
| --- | --- |
| 1 Field | 322px |
| 2 Fields | 160px |
| 3 Fields A / B | A: 105〜106px、B: 63 / 126 / 127px |
| 4 Fields A / B | A: 78〜79px、B: 126 / 127px |
| 5 Fields A / B | A: 62〜63px、B: 63 / 126px |
| 6 Fields A / B | A: 62〜63px、B: 62 / 126px |
| 7 Fields A / B | A: 62〜63px、B: 126px |
| 8 Fields | 62〜63px |
| 9 Fields | 63px（最上段のみ） |
| 10 Fields | 横幅いっぱいの枠なし（全枠122px幅） |

例えば **7 Fields A の最上段は246×63px** で、曲名とアーティスト名を2行で配置できた。
シミュレーターは各枠に同じ Data Field を複製するため、実機で他の項目と並べた表示は別途確認する。

英語設定では日本語サンプルの文字が描かれないことを確認した。日本語表示は端末の言語・フォントに依存する。

## 残る開発環境の問題

`nowplaying-settings.json` は正常に生成されるが、シミュレーターの
`File > Edit Persistent Storage > Edit Application.Properties data` は
`No settings file found for this app` を表示した。絶対パスで起動し直しても再現する。
原因は未特定。設定による固定サンプルの UI 検証は次回へ残し、今回の描画確認には初期値の自動切替を使った。
サイドロードした実機アプリの Connect IQ アプリ経由の設定変更も未確認。

## シミュレーターで確認すること

1. `Now Playing Demo` を起動し、15秒ごとの5種類のサンプル切替を確認する。
2. 1枠、2枠、3〜7枠の A/B、および最大分割を確認する。
3. 横幅いっぱいの1枠を含むレイアウトと、その枠の幅・高さを記録する。
4. 曲名・アーティスト名が重ならず、枠外へはみ出ないか確認する。
5. 長い曲名と長いアーティスト名の末尾が `...` になるか確認する。
6. 日本語サンプルが表示されるか確認する。英語設定・日本語設定の両方で試す。
7. 背景の白・黒と、狭い枠の1行表示を確認する。
8. テストビルドでテストを実行し、結果をこのファイルへ追記する。

## 実機で確認すること

1. Edge 530 を USB 接続し、ビルドした `bin/nowplaying.prg` を `GARMIN/APPS` にコピーする。
2. 安全な停止状態で、アクティビティプロフィールのデータページに Connect IQ の `Now Playing Demo` を追加する。
3. 実機でも横長1枠の配置・省略・日本語が成立するか確認する。
4. アクティビティの開始・一時停止・再開で表示が続くか確認する。
5. 他の項目と共存した際のメモリ不足・エラーを確認する。

横長の枠をアプリ側から強制することはできないため、ユーザーがデータ画面のレイアウトを選ぶ。
実機で動いた後に、通信の実験へ進む。
