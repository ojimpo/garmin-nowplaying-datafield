# 表示と動作の確認

## 実行記録

2026-10-24、Windows 上で実施。

| 確認 | 結果 |
| --- | --- |
| SDK 9.3.0 + Java 17 によるデバイス指定なしの strict 型チェックビルド | 通常・テスト用ともに BUILD SUCCESSFUL |
| Edge 530 を指定したビルド | デバイス定義の取得に Garmin ログインが必要なため保留 |
| Monkey C テストの実行 | Edge 530 シミュレーター設定後に実施予定 |
| 画面分割・日本語・実機 | 未確認 |
| iPhone からの Spotify 情報取得・送信 | 未実装 |

デバイス指定なしのビルドには `Invalid device id ... edge530` の警告が出る。
これは構文・型の確認に限られ、Edge 530 向けの互換性・メモリ・フォント・実行を検証した結果ではない。
`bin/generic*.prg` は端末へ配布しない。

## シミュレーターで確認すること

1. `Now Playing Demo` を起動し、15秒ごとの5種類のサンプル切替を確認する。
2. 1枠、2枠、3〜7枠の A/B、および最大分割を確認する。
3. 横幅いっぱいの1枠を含むレイアウトと、その枠の幅・高さを記録する。
4. 曲名・アーティスト名が重ならず、枠外へはみ出ないか確認する。
5. 長い曲名と長いアーティスト名の末尾が `...` になるか確認する。
6. 日本語サンプルが表示されるか確認する。英語設定・日本語設定の両方で試す。
7. 背景の白・黒と、狭い枠の1行表示を確認する。
8. テストビルドでテストを実行し、結果をこのファイルへ追記する。

## 実機で確認すること

1. Edge 530 を USB 接続し、ビルドした `bin/nowplaying.prg` を `GARMIN/APPS` にコピーする。
2. 安全な停止状態で、アクティビティプロフィールのデータページに Connect IQ の `Now Playing Demo` を追加する。
3. 実機でも横長1枠の配置・省略・日本語が成立するか確認する。
4. アクティビティの開始・一時停止・再開で表示が続くか確認する。
5. 他の項目と共存した際のメモリ不足・エラーを確認する。

横長の枠をアプリ側から強制することはできないため、ユーザーがデータ画面のレイアウトを選ぶ。
実機で動いた後に、通信の実験へ進む。
